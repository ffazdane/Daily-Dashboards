# Daily dashboard workflow

Create a visual one-page daily FazDane market dashboard optimized for mobile. Cover stocks/options, AI/technology, Fed/economy; include Market Regime Score, sector rotation, MAG7 scorecard, VIX/IV/put-call/gamma (mark unverified metrics), five 1–20 trading-day opportunities, economic events, and five sourced market-moving headlines with relevant images. Clearly distinguish verified facts and timestamps from tactical interpretations. In EVERY delivery, create a self-contained, interactive mobile HTML dashboard and a one-page PNG snapshot as actual downloadable artifacts. Verify the exact generated file paths exist before including sandbox links. Include clearly labeled clickable Markdown download links to both artifacts prominently at the top of the delivered briefing. Do not invent file links, and do not use sandbox URLs as GenUI.openUrl destinations. If file creation or verification fails, explicitly state that and provide the dashboard inline instead of a broken link. Avoid claiming the HTML is a permanently hosted public URL; describe it as a downloadable local HTML file. Embed every chart and diagram from the briefing directly in the HTML, including regime gauge and historical trend, premarket performance bars, sector rotation flow diagram, MAG7 and sector scorecards, volatility cards, Fed probability visualization when verified, interactive trade filters, economic calendar, five embedded headline illustrations with source links, and interactive confirmation checklist. Use responsive inline SVG/CSS/JS with no external dependencies, official FazDane logo and explicit financial disclaimer. Do not invent missing observations. Publish the enhanced dated HTML to ffazdane/Daily-Dashboards on main under reports/FazDane_Daily_Market_Dashboard_YYYY-MM-DD.html, update homepage and archive without duplicates, verify committed content and report GitHub Pages deployment status separately; if publishing fails, retain local artifacts and disclose failure.
